# AWS AI-DLC와 Superpowers brainstorming 비교 정리 요청

[[career/kakaogames/aws-aidlc-workflows-v2-study|AWS AI-DLC Workflows 2.0 분석]]에 Superpowers의 `brainstorming` 접근법과의 비교를 추가로 정리한다.

## 비교 범위

- 문제·요구사항을 구체화하는 질문 방식
- 설계 대안을 탐색하고 선택하는 절차
- 사용자 승인 또는 검토가 개입하는 지점
- 산출물과 다음 구현 단계로의 연결 방식
- DBA Agent 등 실제 업무 흐름에 적용할 때의 장단점

현재 메시지만으로는 비교 결과나 완료 기한이 확정되지 않았으므로 후속 조사·정리가 필요하다. 완료 후 [[career/kakaogames/2026|2026년 작업 내역]]과 연결하거나 기존 AI-DLC 학습 노트에 병합한다.
