# raw/ — 원본 자료 보관소

여기는 **내가 넣는 곳**이다. 에이전트는 읽기만 하고 **수정·삭제하지 않는다**.

## 넣는 방법

파일을 그냥 이 폴더에 떨어뜨리면 된다. 이름 규칙은 없지만 `YYYY-MM-DD-슬러그.md` 형태면
나중에 시점을 찾기 쉽다. 마크다운, 텍스트, PDF, 이미지(스크린샷·화이트보드 사진) 모두 된다.

넣은 뒤 세션에서 한마디만 하면 된다:

> 자료 넣었어

그러면 에이전트가 `raw/`에서 아직 처리하지 않은 파일을 찾아 `wiki/`에 반영한다.
자세한 규칙은 저장소 루트의 `CLAUDE.md`를 참조.

## 폴더

- `raw/` — 아직 위키에 반영되지 않았거나, 반영됐지만 원본을 남겨둔 자료
- `raw/archive/` — 이미 위키로 승격이 끝난 원본. 대조용으로만 남긴다

## 넣지 말 것

계정, 비밀번호, 토큰, 접속 문자열, 내부 IP, 고객 데이터.
이런 값이 섞인 자료는 해당 부분을 지우고 넣거나, 아예 넣지 않는다.
위키에는 "자격증명은 사내 vault 참조" 처럼 **위치만** 기록한다.
